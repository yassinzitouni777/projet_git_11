# Gestion des tâches (Python)

Application console simple pour gérer des tâches quotidiennes.

## Fonctionnalités
- Ajouter une tâche (titre non vide)
- Afficher toutes les tâches numérotées
- Rechercher une tâche par mot-clé
- Quitter le programme

## Étapes réalisées
1. Création du menu et de l'ajout de tâches
2. Ajout de l'affichage et de la recherche
3. Documentation du projet et publication sur GitHub

## Exécution
Ouvrir le dossier dans VS Code, ouvrir `main.py`, puis cliquer sur
le bouton « Run Python File ».
